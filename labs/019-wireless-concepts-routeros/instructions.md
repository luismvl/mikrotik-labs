# Contexto

RouterOS incluye un menu dedicado `/interface wireless` para gestionar interfaces radio. Antes de configurar un AP o un cliente, es fundamental entender los conceptos: bandas, modos de operacion, canales, potencia y seguridad. Este laboratorio es un cuestionario de autoevaluacion sobre dichos conceptos.

# Objetivos

1. Identificar las bandas de frecuencia disponibles en MikroTik (2.4 GHz y 5 GHz).
2. Diferenciar los modos wireless (ap-bridge, station, bridge, etc.).
3. Conocer los protocolos de seguridad wireless soportados (WEP, WPA, WPA2, WPA3).
4. Entender la relacion entre el menu `/interface wireless` y la configuracion de interfaces fisicas.

# Tareas

1. Responde las preguntas del cuestionario sobre wireless en RouterOS.
2. Identifica que modo wireless se usa para un AP que debe dar servicio a clientes y tambien conectarse a otro AP.
3. Explica la diferencia entre una red abierta, WEP y WPA2-Personal.
4. Describe brevemente como se elige un canal en 2.4 GHz para evitar interferencias.
