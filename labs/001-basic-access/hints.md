# Pistas

1. En este laboratorio el acceso es remoto: usa directamente el host del panel de acceso y el puerto mapeado.
2. El usuario por defecto es `admin` y la contrasena inicial es `admin`.
3. Para cambiar la contrasena por SSH usa el comando `password`.
4. Si un servicio no responde, revisa `/ip service print` para confirmar que esta habilitado.
5. WebFig es la interfaz web; accede con `http://<host>:43281`.
