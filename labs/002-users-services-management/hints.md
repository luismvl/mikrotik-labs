# Pistas

1. Usa `/system identity set name=...` para cambiar el nombre visible del router.
2. Los grupos de usuario controlan permisos; `full` es el mas amplio.
3. No elimines el usuario `admin` hasta confirmar que el nuevo usuario funciona.
4. Puedes deshabilitar varios servicios en una sola linea separando nombres con comas en WinBox, o con varios comandos en CLI.
5. Recuerda que algunos servicios comparten puertos o dependencias; si deshabilitas `www`, WebFig dejara de funcionar.
